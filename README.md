# Strat Master P.A
Signal-only futures setup scanner (MES/MNQ/MGC). Suggests Strat setups (2-1-2, 3-1-2, 2-2, 1-2-2, 3-2-2) with entry / stop / take profit — you place every trade yourself.

Includes Strat Trader–style attributes inside this app: multi-TF continuity, long-candle 50% targets, Bayesian confidence, stats by setup/hour/continuity, suggestions you Apply yourself, and Apex 25K EOD limit reference.

**My Trades** is Strat Master's own journal on this device (not Strat Trader's journal). Optional read-only link to Strat Trader shows webhook alerts only.

Never places orders or connects to a broker. Data: Yahoo Finance delayed candles via GitHub Actions sync (data branch) or optional local PC relay.
